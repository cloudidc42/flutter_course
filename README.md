## วิธีใช้หลักสูตรนี้

1. เริ่มต้นที่ Part 01 และทำตามลำดับ
2. แต่ละ Part มีตัวอย่างโค้ดที่สามารถใช้งานได้จริง
3. ทำ Workshop ในแต่ละ Part ให้ครบ
